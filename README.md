# Verif. – Online Examination System

Verif. is a modern and user-friendly Online Examination System developed using HTML, CSS, and JavaScript.

The system allows students to explore available examinations, attend online tests, answer multiple-choice questions, submit exams, and instantly view their examination results.

## Features

- Clean and professional user interface
- Responsive design for desktop and mobile devices
- Available examinations section
- Multiple-choice online examination
- Interactive question navigation
- Previous and Next question buttons
- Question number navigation
- Countdown examination timer
- Automatic exam submission when time expires
- Answer selection and validation
- Automatic score calculation
- Pass/Fail result
- Percentage calculation
- Recent examination results
- Smooth navigation between sections
- Interactive buttons and hover effects

## Sections

### 1. Home

The Home section introduces the Online Examination System and provides quick access to examinations and results.

### 2. Available Exams

Students can view available examinations such as:

- Mathematics
- Web Development
- Computer Networks
- Database Systems

Each examination displays its duration, number of questions, and availability status.

### 3. Take Exam

The examination interface allows students to:

- View questions
- Select answers
- Navigate between questions
- Track remaining time
- Submit the examination

### 4. Results

After submitting an examination, the system automatically calculates:

- Total questions
- Correct answers
- Wrong answers
- Percentage
- Pass/Fail status
- Time taken

The latest result is also displayed in the examination history.
